## 基本条件（三者必须完全相同，否则整张表作废）

| 项目 | 取值 |
|---|---|
| 工艺库及版本 | **GPDK045**（gsclib045 v3.5 的再表征版，Cadence 随 Innovus 发布的 45nm 通用库）：477 个单元，其中 324 逻辑 + 126 时序；物理尺寸取自 `gsclib045.lef`（单元高 1.71 µm，487 个 MACRO） |
| 综合工具及版本 | **Cadence Genus 15.20-p004_1**（GENUS15.20，built 2015-11-14） |
| 功耗工具及版本 | **无独立功耗工具**（VM 上未装 PrimeTime/PowerArtist）。功耗由 Genus 在同一次映射后用 `set_switching_activity` + `report_power` 给出，因此面积/时序/功耗三项出自同一份映射结果 |
| 工艺角 / 电压 / 温度 | `TT_25C_1V20`（`typical.lib`：process 1.0 / 1.20 V / 25 °C）。另有 `FF_0C_1V32`（fast.lib）、`SS_125C_1V08`（slow.lib），用 `make synall` 跑 |
| 测试集（seed） | `20260101` |
| 驱动负载 / 输入转换时间 | 输入驱动单元 `BUFX4`；输出负载 0.016 pF；输入转换时间 0.05 ns；时钟不确定性 5% 周期；I/O 延迟各 25% 周期（全部定义在 `config/pdk.mk`） |
| 统计窗口 | 从开始装载到结果全部输出（含格式转换、运算、存储、控制开销）；周期数取仿真 `lat_max`，时延 D = 周期数 / 频率 |

> **两条必须写进报告的说明**
> 1. 库的 `.lib` 里所有单元 `area` 都是 **0.0**（演示库被剥掉了面积字段）。面积只能来自 LEF，
>    流程强制 `read_physical -lef`，且面积解析为 0 时 `make syn` 直接失败 —— 所以表里的面积不是 0。
> 2. 综合阶段**未插时钟树、未布线**。面积不含布线开销，时序不含寄生 RC，功耗是静态估计而非仿真功耗。
>    三个方案在同一口径下比较，相对值（A₀/A、D₀/D、E₀/E）有效；绝对值不可当作流片数据。
